# Tests d'usage (lot D)

Ce dossier contient de quoi mener les séances, pas leurs résultats.

| Fichier | Sert à |
|---|---|
| `guide-seance.md` | Dérouler une séance : ce qu'on dit, les tâches, ce qu'on ne fait pas |
| `fiche-observation.md` | Noter une séance (un exemplaire par participant) |
| `recrutement.md` | Trouver les participants : message, critères, accord |
| `distribution.md` | Mettre l'app dans des mains : ce qui est vérifié, ce qui reste à faire |
| `modele-synthese.md` | Résumer une étape et en tirer des décisions |

## Où vont les notes

**Pas dans ce dépôt.** Il est public. Une fiche remplie contient des citations, des habitudes et
parfois des détails sur un chien et son foyer, même sans nom. Les fiches remplies et les synthèses
vont dans le Vault de Guillaume, sous `1-Projects/`, dans un dossier daté par étape (par exemple
`trufflo-tests-d1-2026-10`). Les participants y sont P1, P2, P3, sans nom, sans numéro de
téléphone, sans adresse.

La synthèse, elle, peut être résumée dans une ADR du dépôt si elle change une décision : on y
écrit la décision et le motif, jamais une citation identifiable.

## Ce que ces séances ne prouvent pas

Cinq personnes trouvent des problèmes. Elles ne mesurent ni une demande, ni un prix, ni une
rétention. Une phrase comme « c'est joli » n'est pas un résultat.
